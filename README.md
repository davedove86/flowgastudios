# Flowga Studios

Yoga studio website for [Flowga Studios](https://github.com/davedove86/flowgastudios) — classes, instructors, studio locations, and The Yoga Handbook.

## Pages

- Home — hero, about, testimonials, Durham / Sunderland / Newcastle maps
- Classes — filter by instructor, class cards
- Instructors — team bios
- The Yoga Handbook — excerpts and ebook checkout (demo)
- Class details — times, tags, booking request

## Local development

```bash
npm install
npm run dev
```

The app listens on port 8080.

```bash
npm run build
npm run typecheck
```
